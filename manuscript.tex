\begin{abstract}
\noindent
A predicted probability is not a credit decision. After the models are fit, this study separates which model to keep from which threshold turns its probability into an action. The knowledge is one false-negative cost ratio, fixed before any test account is scored. On the UCI credit-card default file (30,000 accounts; 6,636 defaults, 22.12\%), four models were fit without class weights. Prediction-first selection kept histogram gradient boosting, the highest validation F1 at threshold 0.50 (0.4682), then tuned only its threshold. Decision-first selection searched every model and threshold for the lowest validation cost. Leaving 0.50 cut test cost from 0.7522 to 0.5762 at ratio 5, from 1.4605 to 0.7392 at ratio 10, and from 2.8772 to 0.7815 at ratio 20; those intervals excluded zero. At ratio 2 the threshold contrast was not statistically conclusive. Decision-first selection was cheaper at ratio 2 (relative difference 0.0406; interval 0.0050 to 0.0210). At ratios 5, 10, and 20 the strategy interval included zero. Across 20 splits (seeds 42 through 61) the mean gain from leaving 0.50 excluded zero at every ratio and exceeded the mean gap between the rules. The public file is not a startup portfolio.
\end{abstract}

{\sloppy\noindent\textbf{Keywords:} Cost-sensitive classification; Decision support; Decision threshold; Knowledge-based system; Credit scoring; Model selection\par}

\section{Introduction}
A probability of default is not a credit decision. Accuracy comparisons, cost-sensitive training, class-imbalance corrections, and profit-driven scoring are already a large literature \cite{idbenjra2024,li2024,kopanja2025,xing2024,shen2024,crella2025,wangchi2024,zhao2024,xukou2025,xuergu2026,tang2024,mushava2024,weng2025,nazri2025,sun2024,ranjan2024,chen2024,tu2025,kwon2025,yang2024,chang2024,ding2025,wang2025ejor,vikas2025}. Less attention has been given to two choices made after the fit: which model to keep, and which threshold turns its probability into an action under a stated cost ratio. This short communication does not add another accuracy contest. It asks whether the cost saving comes from choosing a different model, or from changing the threshold of a model already chosen.

Prediction-first selection fixes the model by validation F1 at threshold 0.50, then tunes only the threshold. Decision-first selection chooses the model and the threshold together by validation cost, and the test set is scored only after both rules are locked. In this study the knowledge component is deliberately compact: an externally specified asymmetric cost preference is an explicit decision rule rather than learned inside the classifier, and the inspectable object is the pair \((r,t)\). The contribution is Eq.~\eqref{eq:cost}, the two rules in Eqs.~\eqref{eq:strategy-a} and \eqref{eq:strategy-b}, and the same lock on 20 stratified splits of the public Default of Credit Card Clients file \cite{yeh2009,yehdata}. Decision-first selection is not claimed to be uniformly superior.

\section{Decision framework}
\label{sec:framework}
The positive class is default payment next month. The decision predicts default when the probability is at least a threshold \(t\). A false positive is a predicted default that does not occur, and a false negative is a missed default. With \(N\) cases, the normalized cost per case at false-negative ratio \(r\) is
\begin{equation}
c(r)=\frac{1\cdot\mathrm{FP}+r\cdot\mathrm{FN}}{N}.
\label{eq:cost}
\end{equation}
The ratio \(r\) is a scenario weight, not an estimated monetary loss. The values used here are \(r\in\{2,5,10,20\}\). If a score is treated as a probability, Eq.~\eqref{eq:cost} is minimized at the reference threshold \(1/(1+r)\): 0.33, 0.17, 0.09, and 0.05. The grid search does not impose that formula. The threshold grid is \(\mathcal{T}=\{0.01,0.02,\ldots,0.99\}\).

Let \(m\) index the candidate models, and let \(\mathrm{F1}_{\mathrm{val}}\) be the positive-class F1 on the validation split. Prediction-first selection fixes one model, then one threshold for each \(r\):
\begin{equation}
\begin{aligned}
m^{*}&=\arg\max_{m}\mathrm{F1}_{\mathrm{val}}(m,0.50),\\
t_{A}^{*}(r)&=\arg\min_{t\in\mathcal{T}}c_{\mathrm{val}}(m^{*},t,r).
\end{aligned}
\label{eq:strategy-a}
\end{equation}
F1 at 0.50 is a different objective from the cost minimized in the second line, so the model is chosen under one rule and then operated under another. If several models share the highest validation F1 at 0.50, the tie goes to the lower validation cost at that threshold for the \(r\) under consideration, then to alphabetical model name. A threshold tie goes to the higher validation F1, then to the lower threshold.

Decision-first selection searches the pairs directly:
\begin{equation}
\bigl(m_{B}^{*}(r),t_{B}^{*}(r)\bigr)
=\arg\min_{m,\,t\in\mathcal{T}}c_{\mathrm{val}}(m,t,r).
\label{eq:strategy-b}
\end{equation}
Ties go to the higher validation F1 at that threshold, then to model name, then to the lower threshold. Class imbalance is not handled with class weights. The grid search carries both the base rate and the cost ratio. Neither rule may use the test split.

\section{Experimental design}
The source file is the UCI Default of Credit Card Clients workbook \cite{yeh2009,yehdata}: 30,000 accounts and 6,636 defaults (22.12\%), still used for predictive comparisons \cite{bhandary2025}. The identifier is dropped. The public file contains SEX, and algorithmic bias in credit scoring support systems is an active design problem \cite{lin2026}. SEX is removed before the split because a credit decision policy should not use sex, and this study does not estimate a sex effect. Excluding SEX blocks its direct use. It does not establish algorithmic fairness, because other predictors may carry proxy information. A formal fairness assessment is outside this study. The other 22 predictors stay as numeric codes, including education, marriage, age, repayment status, bills, and payments.

The split and the bootstrap each use seed 42. The stratified split holds out 6,000 test accounts and then 6,000 validation accounts, leaving 18,000 training accounts. Models are fit only on the training accounts. Selection uses only the validation accounts. Test probabilities are computed after every model and threshold has been chosen.

Four models produce probabilities, with random seed 42 wherever the implementation accepts one, and with no class weight. A logistic regression uses $C = 1$, after a standardizer, with the library's default L2 penalty. The other models are a random forest (200 trees, depth 10, minimum leaf size 5), histogram gradient boosting (200 iterations, depth 6, learning rate 0.1), and XGBoost (200 trees, depth 5, learning rate 0.1). Thresholds run from 0.01 to 0.99 in steps of 0.01. The decision predicts default when the probability is at least the threshold. Validation Brier scores, which did not enter selection, were 0.1456 for logistic regression, 0.1342 for the random forest, 0.1368 for histogram gradient boosting, and 0.1356 for XGBoost. The four scores lie in a narrow band. That is not a formal calibration proof. For ratio 20 only, a sensitivity repeats the validation search on thresholds 0.001 to 0.009 in steps of 0.001 and keeps the lower validation cost. The primary tables stay on the original grid.

Uncertainty on the primary split is a paired bootstrap of the test accounts: 1,000 resamples, percentile interval from 2.5 to 97.5, seed 42, same resamples for every contrast, and no refit. A positive strategy difference means decision-first selection has the lower test cost; the relative difference divides that gap by the prediction-first test cost. If an interval includes zero, the difference is not statistically conclusive. Seeds 42 through 61 repeat the stratified sizes, 20 splits in total, with the model random seed held at 42. The minimum, median, and maximum are a stability range, not a confidence interval. A separate percentile bootstrap of the mean of the 20 split-level differences, also 1,000 resamples and seed 42, describes these partitions of this file. It is not the seed-42 test-set bootstrap.

\section{Implications for the operating decision}
The chain is probability, preference, policy, then action. The model estimates a default probability, the knowledge layer states \(r\), the decision layer returns \(t\), and the action predicts default when the probability is at least \(t\). When \(r\) changes, the same model can keep its probabilities and publish a new threshold. On this file, \(r=10\) moves the prediction-first rule from 0.50 to 0.09. An organization with a probability model does not, on this evidence, need to replace that model every time the cost ratio changes. Online consumer credit is already a risk-management task \cite{zhu2024}. Research on digital transformation treats the organizational resource, rather than the software alone, as what has to change \cite{piccoli2024}. Here that resource is the pair \((r,t)\). The file contains Taiwanese credit-card clients \cite{yeh2009}, not a startup portfolio, and \(r\) is a scenario weight rather than a measured loss.

\section{Conclusion}
The useful output is a threshold tied to a stated cost ratio. On the seed-42 test set, leaving threshold 0.50 reduced cost by a margin whose interval excluded zero at \(r=5\), \(r=10\), and \(r=20\), and the strategy difference was not statistically conclusive at those three ratios. At \(r=5\) the point estimate favored prediction-first selection. Across seeds 42 through 61, the mean gain from leaving 0.50 excluded zero at every ratio, including \(r=2\), where the seed-42 test interval still included zero. Those are different questions, and the min-to-max range is not a confidence interval. Extending the \(r=20\) grid to 0.009 did not lower seed-42 test cost. The validation Brier scores are close, which is not a calibration proof. SEX was excluded from the predictors, was not used to estimate a sex effect, and that exclusion does not establish fairness.
